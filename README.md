# TCG Remote Overlay


ブラウザ上で完結するリモート対戦や、Discord等の画面共有を用いた対戦を強力にサポートする、トレーディングカードゲーム（TCG）用オーバーレイツールです。「遊戯王OCG」や「ホロライブOCG」に特化した機能を備えつつ、あらゆるTCGで汎用的に利用可能です。

## 🌟 主な機能

### 🛰️ 高機能オーバーレイ (OverlayWidget)
- **自由自在な配置**: マウス操作でウィジェットを画面内の好きな場所に移動、回転、拡大縮小が可能です。
- **優先表示順位管理 (Z-Index)**: ウィジェット間の重なり順をドラッグ＆ドロップで自由に変更可能。
- **最前面表示機能**: 選択中のウィジェットは自動的に最前面へレイヤー移動し、快適な変形操作をサポート。
- **スナップ回転**: 0°/90°/180°/270° に近づくと自動で吸い付くスマート回転機能を搭載。
- **全画面モード**: ブラウザのアドレスバーやタブを隠して、アプリ単体で配信画面のような没入感を実現。
- **レスポンシブ・スケーリング**: ウィンドウのサイズを変更すると、1920x1080を基準としてウィジェットの大きさが自動的に調整され、レイアウトと視認性を完璧に維持します。
- **スマート・アクションバー**: 複数選択時にグループ化操作が可能なフローティングバーが表示され、画面端やローテートハンドルの邪魔にならないよう動的に配置されます。
- **ウィジェット・グループ機能**: 複数のウィジェットをグループ化して、まとめて移動や回転が可能です。
- **スマート・リセット**: 単体またはグループ化されたウィジェットを、結合時のレイアウトを維持したまま瞬時に画面中央へ戻すことができます。
- **マイレイアウト機能**: 
    - 現在の配置、グループ構成、重なり順、および**映像調整設定**を名前を付けて保存、呼び出しが可能です。
    - **「他を隠す」機能**: 適用時に他のウィジェットを自動的に非表示にするオプションを選択可能。
    - **コンテキスト依存の保存**: 入り口（アクションバー/設定メニュー）に応じて、選択中のみ保存するか全体を保存するかを自動判別。
    - 外部JSONファイルとしてのエクスポート・インポート、およびフォルダからのデフォルトレイアウト自動読み込みに対応。
- **誤操作防止 (Action Shield & Interaction Exclusion)**: 
    - ウィジェット選択中は内部ボタンが反応しないようガード。
    - 設定メニュー、映像調整パネル、アクションバー上での操作が背景のウィジェットに影響を与えないよう入力を遮断。

### 🎴 独立したウィジェット構成
特定の「モード」に縛られず、以下のウィジェットを自由に組み合わせて対戦画面を構成できます。

- **カードウィジェット**: 
  - **空のキャンバス設計**: 初期状態ではアセットを持ち込まず、ユーザーのローカルフォルダからカード画像を読み込んで使用します。
  - **2つの表示モード**: 
    - **ライブラリモード**: ローカルフォルダを指定し、メタデータ（読みがな、カテゴリー等）に基づいた検索・表示。
    - **シンプルモード**: 好きな画像ファイルをブラウザに直接ドラッグ＆ドロップして即座に表示。
- **ドラッグ＆ドロップによるモード自動切替**: ウィジェットに画像ファイルを落とせば「シンプルモード」、フォルダまたはZIPファイルを落とせば自動で「ライブラリモード」に切り替わります。
  - **ZIP直接展開サポート**: カードテンプレート等のZIPファイルをウィジェットへドロップするだけで、内容を自動解析・展開し、即座に使用を開始できます。展開前にファイルサイズを確認できるほか、高精度な進捗ゲージ（プログレスバー）により残り時間を把握可能です。Windows環境特有のパス不具合や文字制限にも完全対応。
  - **テンプレート配布**: 設定メニューの「操作説明」タブから、推奨されるフォルダ構成と設定ファイルの雛形（zip）をダウンロード可能。独自のカードリスト作成を強力にサポートします。
  - **ピン留め機能**: 最大1,000枚まで登録可能。ドラッグ＆ドロップによる自由な並び替えに対応。
  - **状態の自動復元**: ブラウザを閉じても、最後に表示していた画像やフォルダ、ピン留め状態が自動的に復元されます。
- **ライフ計算機**: 
  - 直感的な十キー操作による管理、履歴ログ、Undo/Redo対応。
  - Player 2側を自動で180度反転させるオート反転機能。
- **SPマーカー**: 
  - ホロライブOCG向けのSP状態管理ツール。
- **3D物理ダイス・コイン**: 
  - リアルな挙動の3D物理アニメーション。
- **堅牢な映像背景システム**: 
  - カメラや画面共有の接続ミス、デバイス競合（使用中）、物理的な切断を自動検知して具体的な対処法を案内。
  - **カメラデバイス選択**: 複数のカメラが接続されている場合、設定メニューまたは起動画面から使用するデバイスを切り替え可能。

### 🎲 共通機能
- **表示プリセット**: 「遊戯王」「ホロライブ」などのプリセットを選択することで、推奨されるウィジェットの組み合わせを瞬時に呼び出せます。
- **高機能設定メニュー**: 
    - 「ウィジェット」「背景・映像」「マイレイアウト」「操作説明」「ショートカット」などのタブに整理され、必要な項目に素早くアクセス可能。
    - 背景の右クリックや `Esc` キーによる直感的な開閉操作に対応。
- **リアルタイム同期**: `BroadcastChannel API` により、検索、ピン留め、ウィジェットの表示状態などを複数のウィンドウ・タブ間で完全に同期します。無限ループ防止ガードを搭載し、安定した同期を提供します。
- **強制ダークモード**: UI全体はOSの設定に関わらず、常にダークテーマ（暗色背景）で動作するよう最適化されています。
- **セッション管理**: 同一種別の画面が重複して開かれた場合、古いインスタンスを自動終了させる安全装置を搭載。

## 🚀 使い方

### 推奨ブラウザ

- **Google Chrome** または **Microsoft Edge**（デスクトップ版）
- カード画像のフォルダ読み込み機能（File System Access API）がChromium系ブラウザにのみ対応しているため、FirefoxやSafariではフル機能を利用できません。

### セットアップ

1.  **リポジトリをクローン**
    ```bash
    git clone https://github.com/TCGSupporterLab/tcg-remote-overlay.git
    cd tcg-remote-overlay
    ```

2.  **依存関係のインストール**
    ```bash
    npm install
    ```

3.  **起動**
    ```bash
    npm run dev
    ```

### 配信ソフト（OBS等）での使用（オプション）

1.  **オーバーレイを起動**: アプリ右上の「起動」（タブ単位）または「別窓で起動」（ウィンドウ単位）ボタンをクリックしてオーバーレイを表示します。
2.  **OBSに追加**: 「ソース」→「ブラウザ」を追加し、URLに `http://localhost:5173/?mode=overlay` を入力。
3.  **カードの表示**: 検索画面を開き、ローカルのカード画像が入ったフォルダを選択してカードを検索・表示してください。

## 🖱️ ショートカット (Shortcuts)

ショートカットは、設定メニューが閉じている時のみ有効です（ `Esc` を除く）。

### メニュー・表示設定

| 操作 | キー | 動作 |
| --- | --- | --- |
| **メニュー開閉** | `Esc` / `右クリック` | 設定メニューを表示または閉じます。 |
| **映像ソース切替** | `V` / `Shift + V` | 順方向または逆方向に背景映像を切り替えます。 |
| **映像調整モード** | `A` / `ホイールクリック` | マウスホイール等で映像を移動・拡大できるモードへ切り替えます。 |
| **レイアウト呼出** | `Alt + 0-9` | 保存済みのマイレイアウトを瞬時に呼び出します（複数桁対応）。 |
| **全ウィジェット選択** | `Ctrl + A` | 画面上のすべてのウィジェットを同時選択します。 |
| **非表示** | `Delete` | 選択中のウィジェットをレイアウトから隠します。 |

### ウィジェット操作

一般的なウィジェットおよび特定のツール（カード、ライフ計算機）の操作です。 `※` 印の付いたキーは、カード画像選択画面がフォーカスされている時も有効です。

| 操作 | キー | 動作 |
| --- | --- | --- |
| **全状態リセット** | `R` (長押し) | ※ ダイス・コイン、ピン留め、SPマーカー、ライフ等の全状態を初期化します。 |
| **ダイスを振る** | `D` | ※ 3Dダイスをランダムに振ります。 |
| **コイントス** | `C` | ※ 3Dコインを投げます。 |
| **ダイス/コイン** | `.` (テンキー) | ※ ダイス、または2連打でコイントスを行います。 |
| **SPマーカー操作** | `O` | ※ SP状態の反転、または2連打で強制非表示にします。 |

#### **カード**

| 操作 | キー / マウス | 動作 |
| --- | --- | --- |
| **画像選択画面** | `L` | カード検索画面を別窓（または2連打で別タブ）で開きます。 |
| **画像切替** | `Shift + 0-9` | ※ 選択中のカードを別の画像へ切り替えます（複数桁対応）。 |
| **接続解除** | `左ダブルクリック` | カードウィジェットとフォルダ/外部画像の接続を解除し、初期状態に戻します。 |

#### **ライフポイント計算機**

| 操作 | キー | 動作 |
| --- | --- | --- |
| **数値入力** | `0-9` | ※ 電卓形式で数値を入力します。 |
| **計算実行** | `+` / `-` / `Enter` | ※ 加算、または減算（Enterは減算）を実行します。 |
| **半分** | `/` | ※ 現在のライフを50%にします。 |
| **入力クリア** | `Delete` | ※ 入力中の数値をクリアします。 |
| **対象プレイヤー切替** | `P` / `*` | ※ 計算対象（自分/相手）を切り替えます。 |
| **Undo / Redo** | `Ctrl + Z` / `Y` | ※ ライフ履歴を元に戻す、またはやり直します。 |

## 🛠 技術スタック

-   **Framework**: React 19 (Vite 7)
-   **Language**: TypeScript
-   **Styling**: Vanilla CSS / Tailwind CSS
-   **Icons**: Lucide React
-   **State**: Zustand / IndexedDB (idb-keyval)
-   **Sync**: BroadcastChannel API
