# ローカル開発・ツール管理ルール

## 概要
本プロジェクトでは、スクレイピングツール（`tools/` フォルダ）を公開リポジトリ（GitHub）に流出させず、かつ安全にバックアップ・管理するために「ローカル専用ブランチ」運用を採用します。

## 運用ルール
1. **ブランチ構成**:
    - `main` (または公開ブランチ): `tools/` フォルダは `.gitignore` により除外され、GitHub 上にはアップロードされません。
    - `local-dev-tools` (ローカル専用): `tools/` フォルダの変更履歴を記録・保存するためのブランチです。

2. **バックアップ手順**:
    - ツールを修正・更新した際は、`local-dev-tools` ブランチにおいて `git add tools/` および `git commit` を行います。
    - これにより、誤操作でファイルが消失しても Git の履歴から復元可能です。

3. **公開時の注意**:
    - GitHub へ `push` する際は、必ず `main` ブランチに切り替えていることを確認してください。
    - **絶対に `local-dev-tools` ブランチを GitHub に push しないでください。**

4. **復元方法**:
    - 万が一 `tools/` が消失した場合は、以下のコマンド等で履歴から復元します：
      `git checkout local-dev-tools -- tools/`
