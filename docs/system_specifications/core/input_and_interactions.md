# 入力・インタラクション共通仕様 (Input & Interaction)

## 1. キーボード・ショートカットの待機時間 (Standard Debounce/Double-tap Timers)

ユーザーに一貫したレスポンス体験を提供するため、キーボードの連打（ダブルタップ）や複数桁入力時の確定待機時間を以下の通り標準化しています。

- **標準待機時間: 200ms**
    - 特に個別の指示や機能上の強い制約がない限り、すべての入力待機時間にこの値を適用します。

### 現在適用されている箇所と例外
| 機能 | キー | 待機時間 | 備考 |
| :--- | :--- | :--- | :--- |
| **標準（デフォルト）** | - | **200ms** | 新規実装時はこの値を基本とする。 |
| **カード検索画面呼出** | `L` | 200ms | 1回で別窓、200ms以内の2連打で別タブ。 |
| **SPマーカー操作** | `O` | 200ms | 1回で表面/裏面切替、200ms以内の2連打で強制非表示。 |
| **レイアウト呼び出し** | `Alt + 0-9` | 200ms | 複数桁入力の数字間の猶予。 |
| **全状態リセット** | `R` (長押し) | **1500ms** | 誤操作防止のため。ダイス、SP面、ライフ等を初期化。 |
| **ダイス/コイン** | `.` | **150ms** | レスポンス向上のための個別調整。 |
| **カード表示切替** | `Shift + 0-9`| **250ms** | 途中経過の画像表示を防ぐための個別調整。 |

## 2. マウス・インタラクション (Mouse Interactions)

キーボードだけでなく、マウスの操作にも特定の機能を割り当てています。

| 操作 | 対象 | 動作 | 備考 |
| :--- | :--- | :--- | :--- |
| **左ダブルクリック** | カードウィジェット | **接続解除 / クリア** | ローカルフォルダとの接続、または外部URL画像を解除します。 |
| **右クリック** | 背景（非ウィジェット領域） | **設定メニュー開閉** | メニューが開いている時は閉じ、閉じている時は開きます。 |
| **ホイールクリック** | 背景（非ウィジェット領域） | **映像調整モード切替** | ショートカットキー `A` と同じ動作です。 |

## 3. 実装上の注意 (Development Guidelines)
- ショートカット・バッファやダブルタップ判定を実装する場合、マジックナンバーを使用せず、可能な限り共通の定数またはこの標準時間 (200ms) を意識して実装してください。
- **指示によって調整された例外値（150ms, 250ms等）については、特に変更の指示がない限り、標準の200msよりもそれらの値を優先して維持してください。**
