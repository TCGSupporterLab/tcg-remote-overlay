# タスク：ショートカット表示の洗練とモード名称の統一

## 概要
カード表示ウィジェットにおける2つのモード（ライブラリ/シンプル）の名称がコード内やUIで混在していた問題を解消し、「ライブラリモード」と「シンプルモード」に統一しました。また、テンキーのドット（`.`）と `Shift` キーの組み合わせによるショートカットの競合を解消し、操作の一貫性を高めました。
