# 修正内容の確認：ショートカットとモード名称の洗練

## 修正のハイライト

1. **名称の統一**:
    - `WidgetSections.tsx`: ツールチップが「ライブラリモード」「シンプルモード」に統一されました。
    - `useWidgetStore.ts`: 内部コメントが更新され、モード名称の定義が明確化されました。
    - `CardWidget.tsx`: 画像未設定時の fallback 出し分けにおいて「シンプルモード（画像未設定）」などが使用されます。

2. **ショートカットの競合解消** (`App.tsx`, `CardSearchContainer.tsx`):
    - `Shift + テンキー .` が押された際の `Delete` / `Del` イベントを正確に判別するように強化されました。
    - これにより、LP計算機の入力クリアが行われる一方で、これまで同時に実行されてしまっていた「ダイス（テンキー .）」が無視されるようになりました。

3. **マルチウィンドウでの全状態リセット (`R` 長押し) 対応**:
    - `CardSearchContainer.tsx` から `remote_keyup` イベントがブロードキャストされるようになりました。
    - これにより、カード検索画面がフォーカスされている間でも、`R` キーを長押しすると本体側のリセットタイマーが作動し、全ウィジェットの状態（LP, ダイス, コイン, SPマーカー）が正常に初期化されます。

4. **UIの精緻化** (`ShortcutTab.tsx`):
    - 注釈マーク `※` が、項目名の末尾に右上（上付き文字）で小さく表示されるようになりました。
    - これにより、ショートカット一覧がより洗練された見た目となりました。

5. **ドキュメントの最新化**:
    - `README.md` および `docs/system_specifications/` 配下の複数の仕様書において、上記の名称統一とショートカットの仕様詳細が反映されました。
