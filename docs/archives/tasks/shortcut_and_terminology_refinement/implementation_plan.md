# 実装計画：ショートカットとモード名称の洗練

## 現状の課題
1. **名称の非統一**: カードウィジェットの2つのモードの名称が「ライブラリスキャン/カスタム画像」「ライブラリ/シンプル」など混在しており、用語としての一貫性がない。
2. **ショートカットの競合**: `Shift + テンキー .` がLP計算機の「入力クリア」として意図されていたが、同時に「ダイスを振る（テンキー .）」も誤ってトリガーされていた。
3. **機能の欠落**: カード検索画面（別ウィンドウ等）から本体への「全状態リセット（R長押し）」のショートカットが送信されておらず、操作性が低下していた。
4. **UI表示の改善**: 設定メニューのショートカット説明において、他ウィンドウでも有効であることを示す `※` マークが表示しづらく、項目の末尾に右上表示（上付き文字）するべきだった。

## 実装内容
### 1. モード名称の統一
- **内部値**: `library` / `simple` は維持。
- **UI表示**: ツールチップを「ライブラリモード」「シンプルモード」に変更。
- **ドキュメント**: システム仕様書、README 内の表記をすべて統一。

### 2. ショートカットロジックの改善 (`App.tsx`, `CardSearchContainer.tsx`)
- **Shiftキーの誤判定防止**: `NumpadDecimal` に関し、`Shift` が押されている（または `Delete` / `Del` として認識されている）場合はダイスロールをスキップする明示的なガードを追加。
- **リモート操作の強化**: `CardSearchContainer.tsx` に `keyup` のブロードキャストを追加し、`R` キー長押しによるリセットタイマーを別ウィンドウからでも解除・実行できるように対応。

### 3. 設定メニューUIの修正 (`ShortcutTab.tsx`)
- **上付き文字対応**: `ShortcutRow` に `hasAsterisk` プロパティを追加し、`※` を `<sup>` タグで表示。
- **内容の整理**: 検索画面では不要なショートカット（映像ソース切替等）から `※` を削除し、代わりに対応した「全状態リセット」に付与。

## 期待される成果
- ユーザビリティの向上（一貫した用語の使用、操作ミス（ダイス/クリア）の防止）。
- UIの洗練（上付き文字による上品な注釈表示）。
- 安定したマルチウィンドウ操作。
