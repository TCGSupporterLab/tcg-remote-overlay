# 実装計画: カード画像選択画面でのショートカット連携

## 1. 現状分析
- メイン画面 (`App.tsx`) とカード検索画面は別ウィンドウで動作可能。
- 各画面で固有の `keydown` リスナーが設定されている。
- 通信には既に `BroadcastChannel` が一部で使用されている。

## 2. 実装アプローチ
### A. ショートカットロジックの共通化・分離
- `App.tsx` のショートカット処理を `processShortcut` 関数として抽出し、ローカルの `keydown` とリモート（他ウィンドウ）からのメッセージの両方で呼び出せるようにする。
- `LPCalculator.tsx` のキー処理を `processKey` 関数として抽出し、同様にリモートからの同期に対応させる。

### B. カード検索画面でのブロードキャスト
- `CardSearchContainer.tsx` にグローバルな `keydown` リスナーを追加。
- 入力フィールド (Input/Textarea) への入力中以外の場合のみ、対象のキー入力を `BroadcastChannel` 経由で送信する。

### C. 設定メニューの更新
- `ShortcutTab.tsx` を編集し、`※` 印と「カード画像選択画面でも利用可能」という注釈を追加。

## 3. 変更詳細
- **`App.tsx`**:
  - `processShortcut` 関数の抽出。
  - `tcg_remote_app_shortcuts` チャンネルのリスナー追加。
- **`LPCalculator.tsx`**:
  - `processKey` 関数の抽出。
  - `tcg_remote_sync_lp` チャンネルのリスナー追加。
- **`CardSearchContainer.tsx`**:
  - `keydown` リスナーによるキー入力のキャプチャと送信。
- **`ShortcutTab.tsx`**:
  - 適用される各ショートカットに `※` を付与し、上部に説明を追記。

## 4. 検証計画
- カード検索ウィンドウで `D` を押し、メイン画面でダイスが振られることを確認。
- カード検索ウィンドウで `Shift+1` を押し、カード画像が切り替わることを確認。
- LP計算機の数値入力や加減算が同期されることを確認。
- 検索窓で文字入力中に上記のキーを押しても、メイン画面に影響しないことを確認。
