# タスク: カード画像選択画面でのショートカット連携

## 概要
メイン画面のショートカット（ダイス、コイン、SPマーカー、カード画像切替）およびライフポイント計算機の操作を、カード画像選択画面がフォーカスされている時も利用可能にする。

## 要件
1. カード画像選択画面（別ウィンドウ/タブ）から、メイン画面の以下の機能を操作可能にする：
   - ライフポイント計算機
   - カードウィジェットの画像切替 (Shift + 0-9)
   - ダイス、コイン (D, C, .)
   - SPマーカー (O)
2. 文字入力中（検索窓など）はショートカットが動作しないようにガードする。
3. 設定メニューのショートカット一覧に、選択画面でも利用可能なキーを明示する（※印と注釈の追加）。
4. ウィンドウ間の通信には `BroadcastChannel` を使用する。

## 完了定義
- カード検索中のキー入力がメイン画面に反映されること。
- 文字入力中はメイン画面の状態が変わらないこと。
- 設定メニューの表示が指示通り更新されていること。
