# 修正内容の確認 (Walkthrough): カード表示モード切替時の選択状態解除

## 1. 修正箇所
### `App.tsx`
- **`handleSimpleFileSelect` 内のモード切替**:
    - 個別選択されたファイルを受け取った後、`setSettings({ cardMode: 'simple' })` を行い、同時に `dropAccess()` を呼び出しライブラリモードの接続を解除。
- **設定メニューからのモード切替 (`onCardModeChange`)**:
    - シンプルモード切替時に `dropAccess()`、ライブラリモード切替時に `handleClearSimpleCard()` を実行するように連動。
- **ドラッグ＆ドロップ時のロジック更新**:
    - `onDropFile`, `onDropFolder`, `onUnzipZIP` ハンドル内に、排他的なモード切替のための解除ロジックを追加。

### `docs/system_specifications/features/card_and_sp_marker.md`
- **仕様の明文化**: 「4. カード表示モード」セクションにおいて、モード切替時に他方のモード情報がリセット（自動解除）される排他的な挙動であることを追記。

## 2. 動作確認項目
- **ライブラリモードでフォルダ接続済み** -> **設定メニューで「シンプルモード」に変更**:
    - [x] 接続済みフォルダが解除（`dropAccess`）される。
    - [x] カード検索画面が開いていた場合、閉じられる。
- **シンプルモードで画像を選択済み** -> **ウィジェットにフォルダをドロップ**:
    - [x] ライブラリモードに切り替わり、シンプルモードの画像選択が解除される。
- **個別画像をファイル選択ダイアログで指定**:
    - [x] 画像が正しく反映され、ライブラリモードの接続が解除される。
    - [x] ファイル入力の `value` がリセットされ、同じファイルの再選択が阻害されない。

## 3. 結論
モード切替時に設定を一新することで、「PCに接続したまま個別画像を表示する」といった中途半端な状態を排除し、現在の動作モードとリソースの対応関係が明確化されました。
