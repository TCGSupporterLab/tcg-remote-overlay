# 実装計画: カード表示モード切替時の選択状態解除

## 1. 目的
ライブラリモード（フォルダ接続）とシンプルモード（画像選択）は排他的な運用であり、一方が有効な時は他方のキャッシュや接続情報を解除することで、「接続中だが画像が表示されない」といったUI上の矛盾を解消する。

## 2. 修正方針
- **`App.tsx` 内の `onCardModeChange` (設定メニューからの変更)**:
    - モードが `simple` になる場合、`dropAccess()` を呼び出しフォルダ接続を解除。
    - モードが `library` になる場合、`handleClearSimpleCard()` を呼び出し画像選択を解除。
- **ドラッグ＆ドロップおよびファイル選択時の連動**:
    - `onDropFile` および `handleSimpleFileSelect` の開始時に `dropAccess()` を実行。
    - `onDropFolder` および `onUnzipZIP` の開始時に `handleClearSimpleCard()` を実行。
- **検索ウィンドウの閉鎖**:
    - シンプルモードへの切替時は、常にBroadcastChannel経由で検索ウィンドウを閉じるメッセージを送信。

## 3. 影響範囲
- カード表示ウィジェット (`CardWidget.tsx`)
- 設定メニュー (`SettingsMenu.tsx` から渡される props)
- フォルダアクセス状態 (`useLocalCards.ts` と `idb-keyval` のキャッシュ)

## 4. バリデーション
- モード切替時に「画像・フォルダが選択されていません」というメッセージが、切り替えた後のモードに対して正しく表示されること。
- 切替前のモードの古い情報（フォルダ名や画像名）がUIに残らないこと。
- 検索画面がシンプルモード切替時に即座に閉じること。
