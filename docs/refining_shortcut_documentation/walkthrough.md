# 修正内容の確認 (Walkthrough): ショートカット整理とドキュメント更新

## 1. 完了した変更

### UI (`ShortcutTab.tsx`)
- **セクション再定義**: 従来の「メニュー・操作」「ツール」「選択・表示」のような入り組んだ分類を、「メニュー・表示設定」と「ウィジェット操作」の2大分類に集約し、ウィジェット操作内に「カード」と「ライフポイント計算機」をサブカテゴリとして設置。
- **階層化レイアウト**: サブセクションの見出し（カード、LP）は左端に配置しつつ。それらに属する個別のショートカット行のみを右にインデントさせることで階層構造を直観的に表現。
- **全状態リセットの移動**: 全体の初期化操作 `R (長押し)` を、ウィジェット操作セクションの先頭へ配置。
- **名称統一**: キーボード以外の操作（マウス、タッチなど）も含まれるため、「キーボードショートカット」から「ショートカット」へ表記を簡略化。
- **LPセクションの汎用化**: ライフポイント計算機の名称から「(遊戯王)」を削除。

### 機能 (`App.tsx`, `CardWidget.tsx`)
- **マウス操作の追加**: カードウィジェットに対する「左ダブルクリック」で接続解除/クリアを明示的な機能として定義し、ショートカットに記載。
- **メニュー表示中のガード**: 設定メニューが開いている間は、`Esc` キー以外のすべてのショートカット（Ctrl+A, Delete なども含む）を処理しないようガードを強化。

### ドキュメント 更新 (`README.md`, `input_and_interactions.md`)
- **`README.md`**:
    - ショートカット表の並び順と分類を実際のUIと連動するように再修正。
    - マウス操作の明記（右クリックによるメニュー開閉、ホイールクリックによる映像調整、左ダブルクリックによる解除）。
- **`input_and_interactions.md`**:
    - マウス・インタラクションの仕様テーブルを追加。ダブルクリックの動作を定義。
