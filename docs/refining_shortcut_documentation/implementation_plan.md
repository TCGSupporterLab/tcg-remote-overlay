# 実装計画: ショートカット整理とドキュメント更新

## 1. 概要
ユーザーが操作方法をより直感的に理解できるよう、ショートカット一覧（GUI）の構成を全面的に再構築し、名称や説明文の表記を統一します。また、操作の柔軟性を高めるため、カードウィジェット自体のマウス・ダブルクリックによる接続解除機能を公式なショートカットとして組み込みます。

## 2. 実装フェーズ

### フェーズ 1: UI整理 (`ShortcutTab.tsx`)
1. **セクション構成の変更**:
    - `メニュー・表示設定`: 設定メニューや映像、レイアウトなどの大枠の操作。
    - `ウィジェット操作`: 特化した操作（ダイス、カード、LP）をこの配下に集約。
2. **階層構造の導入**:
    - `ウィジェット操作` の中でさらに `カード` や `ライフポイント計算機` をサブセクション見出しで区分。
    - サブセクション見出しは左端、ショートカット項目名は右へインデントさせることで階層を表現。
3. **重要度の再配置**:
    - 最も強力な操作である `全状態リセット (R)` を `ウィジェット操作` の冒頭に配置。

### フェーズ 2: ショートカット機能の微調整
1. **設定メニューとの干渉防止**:
    - `App.tsx` の `processShortcut` を修正し、設定メニューが開いている間は `Esc` 以外のショートカットを無効化。
2. **説明文の最適化**:
    - 「キーボードショートカット」 → 「ショートカット」へと名称を一般化（マウス操作も含むため）。
    - ライフ計算機から「(遊戯王)」を削除し、汎用性を高める。
    - 表記の簡素化（`Del` → `Delete` 等）。

### フェーズ 3: ドキュメントの同期
1. **`README.md` の更新**:
    - 最新のセクション構成と順序に合わせてショートカット一覧表を再構成。
    - 追加されたマウス操作（左ダブルクリック）を追記。
2. **`input_and_interactions.md` の更新**:
    - ダブルタップ（200ms）の基準のみならず、マウスによるインタラクションについても仕様として明文化。
3. **成果物の整理**:
    - 本タスクに関連する文書を `docs/refining_shortcut_documentation` へ集約。

## 3. リスク管理
- インデント調整による視認性の低下を避けるため、CSSクラス (`pl-4` 等) を適切に使い分ける。
- `README.md` の記述ミスがないよう、実際のコード上にあるショートカットキーとの整合性を慎重に確認する。
